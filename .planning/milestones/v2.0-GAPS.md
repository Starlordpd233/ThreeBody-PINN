## Phase 40 resolved gaps

- **GAP-40-04 (RESOLVED-WITH-INSTRUCTION 2026-07-17):** same delegation, **Option
  C**, which **supersedes GAP-40-03's factory shape**. The planner correctly
  STOPPED here: GAP-40-03 ruled that ADVANCE reconstructs
  `(ScheduledWeights, TrainingConfig)` from the factory, but never said whether
  those reach a LIVE `RunController` — which binds its own `ScheduledWeights` at
  construction (`controllers.py:267`) and composes the descended gradient through
  it (`:479`, `current(epoch)` → `_compose_loss_terms`). A seam stopping at the
  `CurriculumController`'s references would leave a live 0→1→2 run minimizing
  stage 0's objective *behind a factory that looks like it fixed it* — worse than
  the original defect, since it defeats detection. Ruling: `stage_factory` yields
  the per-stage **`RunController`** (`k -> RunController`), carrying that stage's
  `ScheduledWeights`/`TrainingConfig`/`GradClipper` (`C_stage`) through one seam.
  Decided by `RunController`'s own docstring — "**Constructed once per stage**"
  (`:232-239`) — which Option A (in-place reconfiguration) would contradict and
  only Option C honors. Adds a binding **model-continuity invariant**: the same
  model instance must carry across stages (curriculum learning persists weights;
  only Adam state resets per SPEC R2), identity-asserted with a typed error on
  mismatch. `stage_factory` is mutually exclusive with `forced_disposition` under
  the existing T-40-09 exactly-one-of guard. GAP-40-03's forced-ADVANCE AC is
  VOID (satisfiable without touching `RunController`) and is replaced by a
  live-objective AC on the `ComposedGateEarnedAdvanceTests` pattern. ERW triage:
  not ERW-grade. Full record: `40-GAPS.md`.

- **GAP-40-03 (RESOLVED-WITH-INSTRUCTION 2026-07-17):** same delegation, **Option

  default and preserves the ratified single-stage Stage-0 path, now documented
  explicitly as PLAT-01. Per-stage `n_adam`/`max_epochs`/`eps_phys`/`eps_energy`
  are **not** invented — SCOPE-19 reserves them for the owner, and they arrive
  through the same seam. The `scheduled_weights.py`/`controllers.py` docstrings
  that assert unconditional per-stage reconstruction are corrected to state the
  real contract. ERW triage: not ERW-grade (object-lifetime/seam placement;
  resolvable from SCOPE-19 + the module's own designed constructor). Full record:
  `40-GAPS.md`.
