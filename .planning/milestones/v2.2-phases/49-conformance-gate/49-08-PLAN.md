failure create a failed `run_start` event before a `ValueError`-family refusal.
Validate decoded metadata as a mapping. At the run-start composition boundary,
catch ordinary `Exception` subclasses (never `BaseException`), retain a valid
census report only when it is a mapping, and normalize the outward exception so
`train.main()` follows its existing controlled refusal path.

Verification:

```bash
.venv/bin/python -m pytest -q tests/phase49/test_inst03_register.py -k 'metadata or runtime_failure'
```

### Task 2 — CR-04 / CR-09: validate scheduler state before use

Use TDD to prove refusal of boolean locked caps, non-finite/non-real caps,
boolean/string/non-finite/negative `n_adam_k`, and boolean/negative
`warmup_length`. Validate every required scheduler scalar before the first
comparison or warmup calculation. Caps must be finite non-negative plain real
scalars (excluding booleans); budgets/warmup must be non-negative plain ints.
All malformed states must raise `ValueError`, allowing both run-start and
stage-boundary callers to persist refusal evidence.

Verification:

```bash
.venv/bin/python -m pytest -q tests/phase49/test_gate01_table.py
```
