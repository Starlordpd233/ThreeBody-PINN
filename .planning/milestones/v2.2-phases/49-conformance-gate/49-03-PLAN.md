Cost: 1 constant bump + 1 additive payload key + 1 restore function + 1 optional constructor parameter. Do not use the re-arm-and-record fallback.

Purpose: D-17 — resume must not silently re-arm; GATE-03's invariant B is only honest if its cross-step state is durable.
Output: a schema-v2 checkpoint contract carrying invariant-B state, with a resume round-trip proven by test.
</objective>
