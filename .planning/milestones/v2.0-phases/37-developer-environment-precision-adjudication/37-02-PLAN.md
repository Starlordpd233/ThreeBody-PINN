<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Registry/installer → local bootstrap | Mutable external artifacts become executable local dependencies. |
| Explicit seed mode → committed replay bytes | The initial lock must be derived without making normal setup a lock writer. |
| Normal setup → existing prefixes/environment | A bad path or drifted state must not cause replacement or mutation. |
| Runtime facts → fingerprint evidence | Host data can include secrets or stale/unverifiable provenance. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-37-03 | Tampering / Elevation | Miniforge bootstrap | high | mitigate | Named official release and checksum, strict compatible-prefix checks, no overwrite/init/delete behavior. |
| T-37-03-SC | Spoofing / Tampering | package and lock identity | high | mitigate | Blocking registry review, committed exact lock, seed validation, installed-state comparison, and lock hash. |
| T-37-03-L | Tampering | seed-to-normal boundary | high | mitigate | Sole writer offers explicit seed/refresh modes; default setup fails when the lock is absent and tests no dispatch. |
| T-37-04 | Information Disclosure | fingerprint output | high | mitigate | Fixed allowlist, secret canaries, no environment/configuration dumps, atomic exclusive writes. |
| T-37-04-T | Tampering / Repudiation | provenance tree | high | mitigate | Review/commit seed output, exact hashes, exclusive evidence directories, JSON-to-Markdown re-derivation. |
</threat_model>
