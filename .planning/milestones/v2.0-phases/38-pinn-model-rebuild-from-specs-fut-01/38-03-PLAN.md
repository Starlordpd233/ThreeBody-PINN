<planner_assumptions>
## Planner assumptions (unresolved SPEC edges + reconciliations — surfaced, not silently dropped)

- **PHYS-02 chain-factor reconciliation (grounded, NOT a gap):** NET-03 / 38-SPEC phrase the contract as "chain-rule factors d^2r'/du^2 = 4*d^2r'/dtau^2, dr'/du = 2*dr'/dtau." The authoritative `pinn_architecture.md` §5.3.1 (Phase 35 contract) resolves this explicitly: the canonical autograd leaf is **u**, and differentiating w.r.t. u uses **no** chain factor; the 2x/4x factors apply ONLY to a direct tau = 2u - 1 leaf. Because the network computes `tau = 2*u - 1` inside forward, autograd of the output w.r.t. the u-leaf already includes the factor of 2 — so the implementation differentiates on the u-leaf and applies NO manual factor. The requirement text merely states the analytic tau<->u relationship; it is not a contradiction. Implement the u-leaf path per §5.3.1.
- **Edge R3 (softening-active / near-collision points) — planner assumption:** at points where two bodies are within ~eps_soft, r_safe -> eps_soft and the residual/gradcheck magnitudes blow up. Handling: (a) the residual raises on non-finite components (fail-loud, inherited from componentwise_ad.py:193-206); (b) gradcheck runs on inputs kept away from the softening floor (a documented minimum pairwise separation in the test fixtures) so the fp64 finite-difference check is well-conditioned; (c) the residual-on-ground-truth probe (38-04) excludes snapshots below a documented pairwise-separation guard and records how many were excluded. This is a planner assumption per the 38-SPEC Edge Coverage note, not a held-out test obligation.
</planner_assumptions>
