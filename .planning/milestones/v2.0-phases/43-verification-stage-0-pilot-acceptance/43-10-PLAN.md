<objective>
Close the ACC-03 once-only held-out enforcement bypasses (CR-01, CR-02). The
evaluator must bind evaluation authority to the owning run's canonical
`evaluation/` directory and claim the held-out budget atomically before the first
held-out access, so alternate output paths cannot replay the split and a
crash/concurrent attempt cannot consume the single allowed evaluation silently.

Purpose: the held-out test set is the milestone's only honest acceptance signal
and its budget is exhausted; the single-use guarantee must be structurally
enforced, not caller-cooperative.
Output: a canonical run-owned evaluation path, an atomic pre-access claim, and
regression tests proving replay and race refusal — all against synthetic fixtures.
</objective>

## Artifacts this phase produces
- `pinn.evaluate` canonical-output enforcement: the resolved output must equal `<run_dir>/evaluation` (a redirect via `--output` is refused).
- A fixed run-owned attempt/claim path (e.g. `<run_dir>/evaluation/evaluation-attempt.json`) created with `os.open(..., O_CREAT | O_EXCL)` immediately before the first held-out read.
- Attempt-finalization logic that resolves the claim into the success/failure receipt without erasing failed or abandoned attempts.
- New tests in `tests/phase43/test_evaluate_gate.py`: alternate-`--output` refusal, atomic pre-claim before access, injected-failure-preserves-attempt, and concurrent-double-claim refusal.
