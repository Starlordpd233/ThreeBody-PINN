# Milestone v1.3: Markdown Conversion Verification & Correction

**Status:** ✅ SHIPPED 2026-05-08

**Total Plans:** 21

## Overview

Verify every markdown conversion against its LaTeX source section-by-section, fix all errors to achieve one-to-one injection fidelity, and produce one authoritative `.md` file per source document.

Six LaTeX sources in `pinn_instruction/original_latex/`:
1. `ctl-instruction/` (8 sections + appendix) — Phase 10
2. `Data-quality-assessment/` (7 sections) — Phase 11
3. `pinn-architecture/` (7 active + 3 inactive sections) — Phase 12
4. `review-of-framework/review_of_framework/` (7 sections) — Phase 13
5. `review-of-framework/stage_strat_revision/` (6 sections) — Phase 14
6. `sampling-method/` (monolithic — 10 logical sections) — Phase 15

**Pattern:** Each phase follows three waves: candidate selection (or provenance note) → section-by-section audit + fixes → archive + finalize.

**Post-ship correction:** On 2026-05-15, the data-quality-assessment SCS gate inconsistency was corrected after user ratification of the gate-led policy. The canonical LaTeX source now separates raw Hamiltonian drift `\epsilon_H` from logarithmic `SCS = \log_{10}(\epsilon_H)`, the regenerated PDF and markdown match, and the closure-audit equation table was updated. This follow-up does not reopen v1.3; it closes the only known SCS gate correction before v1.4 starts.

## Milestone Summary

### Key Decisions

| Decision | Rationale |
|----------|-----------|
| One phase per LaTeX source (6 phases) | Keeps each phase scoped to one document; avoids context-switching across different content |
| Hardest-first ordering (Phase 10 = CTL) | CTL has 3 candidates, heavy math, and \authcomment blocks — validates audit pattern before 5 easier phases |
| Three-wave plan structure per phase | Wave 1 = selection/skeleton; Wave 2 = audit+fix; Wave 3 = archive+finalize — natural checkpoints |
| Manual comparison only (no automation) | Defer automated verification scripts to v2; this milestone is about fixing-in-place, not regenerating |
| One-to-one injection fidelity | Markdown must match LaTeX exactly; no summarizing, paraphrasing, or inter-document reconciliation |
| Inter-document inconsistencies preserved | Source-level inconsistencies are metadata (Source Issues section), not fixes — cross-doc reconciliation is a separate future task |
| Source Issues appended after HR | Separates faithfully converted body from source-level metadata; metadata explicitly excluded from fidelity comparison |
| CAND-02 pattern for single-candidate sources | Skip scoring, record provenance note, no archive needed — Phases 13 and 14 |
| D-02 recall override for candidate selection | When two candidates are close in F1, prefer higher recall (content completeness) over raw F1 |
