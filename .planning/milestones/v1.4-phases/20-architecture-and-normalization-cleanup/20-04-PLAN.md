# ARCH-05 Energy and Mass Realized-Support Cleanup Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the energy and mass normalization support ranges in `ctl_instruction.md` read as realized dataset support rather than defects in the normalizer, gated behind separate completed M9 and M10 evidence packets.

**Architecture:** Evidence-first spec cleanup with two SEPARATE evidence records sharing one acceptance check (AC-ARCH-05). Create/fill M9 (energy) and M10 (mass) from the template, cite the resolution/issue sources AND the dataset documentation for the realized regimes, record one verdict each, edit only the verdict-supported support-range surfaces in `ctl_instruction.md`, then prove closure with a combined support-range audit. This plan runs after 20-02 and 20-03 so its read-only audit sees the final `pinn_architecture.md` and `ctl_instruction.md` surfaces owned by earlier plans.

**Tech Stack:** Markdown framework spec; dataset documentation as realized-support evidence; shell validation with `rg` and `git`. No Python, no tests, no `pinn/` code.
