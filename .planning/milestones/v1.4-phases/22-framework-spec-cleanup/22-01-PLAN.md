The gate must verify the engine handles both `$...$` (inline) and `$$...$$` (block) delimiters, because `ctl_instruction.md` has block-math constructs that must render correctly.     Implement the six layers exactly per design §5.1, code-span/fence handling per the baked-in precision rules:
    - D1 KaTeX `throwOnError` → DEFINITE parse errors.
    - D2 KaTeX `strict` → REVIEW warnings.
    - D3 LaTeX lint (token-aware; code spans/fences excluded): bare multi-char sub/sup via `(?<!\\)[_^](?!\{)[A-Za-z]{2,}` (letters-only, no backslash, no brace, no digit-lead); operator-missing-backslash only in call form `fn(`; brace balance within a span. Bake in the exclusions: escaped `\_`/`\^`, `H_\epsilon`, `m_1r_1` (digit-led), `t_{max}` (braced label). **Additional D3 hardening**: exclude Markdown emphasis contexts (`*…*`, `_…_`, `**…**`) from D3 flagging. Single-letter subscripts/superscripts (e.g., `x_i`, `a^2`) are **not** definitive D3 findings by themselves — they are valid mathematical notation. False-positive suppressions (any D3 exclusion beyond the baked-in patterns) must follow a STOP/user-reviewed path: record the candidate finding, the reason for suppression, and surface it for user review rather than silently dropping it.
    - D4 survivor scan (complete-by-construction): render with the real engine, scan rendered visible text for control-markup that must never survive — literal `$$`, `\command`, `:::`, `{.attr}`, Pandoc multiline-table separator rows, and `: Table …` captions (match the INDENTED caption form, e.g. leading spaces before `: Table`). Footnote tokens `[^n]` are policy-gated at runtime: if `--footnote-policy supported` or the recorded Stage-0 probe says Cursor renders them, suppress that class so `--all` can reach zero; if `unsupported`, flag refs/defs as DEFINITE survivors; if `auto` cannot find a recorded probe and target files contain `[^n]`, exit 3 before scanning. Distinguish `: Table N:` captions (followed by table separator rows) from Pandoc definition-list `:   ` bodies so `sampling_method.md` stays 0-findings (Pitfall 5).
    - D5 backtick-math scan (oracle-guided, REVIEW): scan inline code spans for ASCII-math signatures (`_`, `^`, `=`, `\cmd`, `sqrt`, `sum`, `||…||`, `1e-±n`).
    - D6 prose-math scan (oracle-guided, REVIEW): scan prose outside code/math for ASCII-math signatures.

    Add a CENSUS pass (`--census`): scan each file, fence-excluded for the prose markers, for the all-forms marker set (`Author Comment` / `Author note` / `Historical author note` / `\authcomment` literal, plus `**[…]**` bold notes ONLY when they carry/derive-from an author marker per design §6.1 step 1, plus any other author-comment form discovered). The census input interface is path-based only: accept explicit file paths and/or `--root <dir>` for materialized snapshots; do NOT consume stdin. Emit `{form, file, section-or-anchor, matched-snippet, verbatim-text}` records, a per-comment `text_hash = SHA-256(verbatim-text)`, and a per-file + union count. Each census record must also include `form`, `file`, `section/anchor`, `matched-snippet`, and `verbatim-text` fields. Re-derive against live bytes — report by section/anchor + snippet, NEVER by hardcoded line number (Pattern 3).

    CLI: positional `<file>` = quick single-file run; `--all` = all 3 specs (default to the framework-specs glob) and auto-load committed Phase 22 adjudication allowlists; `--adjudications <path>` = load a targeted REVIEW adjudication allowlist for explicit per-file runs; `--census [--root <dir>] [file ...]` = run path-based census + emit inventory; `--regression` = assert the author-flag regression fixtures are reproduced AND both negative controls are clean; `--selftest` = sanity gate + regression + negative controls in one call; `--footnote-policy auto|supported|unsupported` = branch D4 footnote behavior. Print a deterministic per-file/per-layer report. Exit non-zero on any DEFINITE finding or unadjudicated REVIEW finding (and on `--regression`/`--selftest` failure).     - Exit 1: one or more DEFINITE rendering findings or unadjudicated REVIEW findings detected.

    - Exit 3: missing prerequisite (e.g., Stage-0 footnote probe required but not found).
    - Other non-zero: detector/tool failure (distinct from rendering findings).
