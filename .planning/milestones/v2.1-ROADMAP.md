# Milestone v2.1: Physics-Gate Investigation & trainex-r2 Research Package

**Status:** ✅ SHIPPED 2026-07-24

**Total Plans:** 9 (44-01..05, 45-01..04)

## Overview

v2.1 was the "separately governed investigation" that the v2.0 owner verdict
`adjust` routed (2026-07-22). The v2.0 milestone — the project's first build
milestone — had shipped a working Stage-0 CTL-PINN training stack and then run the
held-out physics-conservation evaluator exactly once, rendering an unequivocal
**FAIL** (`ε_H = 237.21` against a `1e-5` reject threshold, across all 1,500
held-out trajectories). The owner signed `adjust`: retain the mechanical slice,
block full-platform expansion (PLAT-01..07), and investigate the failed gate under
separate governance.

v2.1's job was **not** to fix the physics gate. It was two things:

1. **Diagnose** — from the evidence v2.0 already retained — how and plausibly why
   the Stage-0 model fails, producing a hypothesis-ranked, remedy-abstinent
   diagnosis report (`44-DIAGNOSIS.md`).
2. **Hand off** — assemble the trainex-r2 External Research Workflow (ERW) package
   so the owner's external research can adjudicate the remedy, returning a
   resolution doc that serves as a candidate verdict source for the *next*
   milestone.

The milestone closed at package delivery — the v1.5/v1.6 package-first rhythm. The
remedy (recipe changes, new training, any new evaluation policy) belongs to the
post-resolution-doc milestone.

The investigation ran under hard scope boundaries signed into the v2.0 verdict
(SCOPE-22..26): no held-out evaluation (budget exhausted), no new training runs, no
framework-spec edits, no PLAT-01..07/Stage-1 work, no remedy selection. Any
source-silent physics-adjudication call was surfaced as a STOP-protocol gap and
routed to the owner/ERW — never decided inline.
