## The defect, stated precisely

`preprocess_trajectory` (preprocessing.py:186-191) computes, in order:

```
r_bar, v_bar, R_COM0, V_COM = _com_recenter_and_boost(times, positions, velocities, masses)
permutation  = _canonical_order(masses, r_bar[0], v_bar[0])
masses_ordered = masses[permutation]
r_bar = r_bar[:, permutation, :]        # <- the state this plan exposes
v_bar = v_bar[:, permutation, :]        # <-
```

then applies the rotation gauge (:195-198) and the `D`/`V` scalings (:200-202) to reach
`r_gauge`/`v_gauge`. The adapter stores `pre.masses_ordered` (adapter.py:865 — permuted)
beside `parsed_brutus.positions` (adapter.py:863 — none of the four transforms applied).
Measured consequence: permutation `(2,0,1)` for 1547 trajectories and `(0,2,1)` for 104,
identity for zero; `first_diverging_step = com_recenter_boost` for all 1651.

Why it must be repaired before Phase 47: `K = ½ Σᵢ mᵢ‖vᵢ‖²` and `U = Σ_{i<j} G mᵢmⱼ/‖rᵢ−rⱼ‖`
are both mass-weighted, so `S_H` computed over this corpus is the statistic of a different
three-body system, and `ε_H = 1e-4 · S_H` would mis-scale every energy term downstream.
