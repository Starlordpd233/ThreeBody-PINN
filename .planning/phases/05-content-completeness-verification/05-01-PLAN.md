  <action>
    Create the verification script at `pinn_instruction/original_latex/verification/verify_content.py` with the following components per the research in 05-RESEARCH.md:

    **1. Structure definitions (dataclass)**
    Define all 5 structures with their paths:
    ```python
    @dataclass
    class Structure:
        name: str
        original: Path
        modular: Path
        inactive_files: Optional[list] = None
    ```
    Use exact paths from CONTEXT.md. For pinn-architecture, set `inactive_files=["input_vector_inactive", "advanced_training_inactive", "consolidated_blueprint_inactive"]`.

    **2. normalize_line_endings(content: str) -> str**
    Replace CRLF and CR with LF: `content.replace('\r\n', '\n').replace('\r', '\n')`

    **3. resolve_includes(content: str, base_dir: Path, depth: int = 0) -> str**
    Per D-01: Recursively resolve `\input{path}` and `\include{path}` directives.
    - Match pattern: `r'^(\s*)(\\(?:input|include)\{([^}]+)\})(\s*)$'`
    - Add `.tex` extension if not present
    - Recursively resolve included content
    - Safety limit depth at 10
    - For `\include{}`, do NOT add `\clearpage` markers (per research pitfall #1)

    **4. normalize_whitespace(content: str) -> str**
    Per D-03:
    - Strip trailing whitespace from each line: `line.rstrip()`
    - Collapse multiple blank lines to single blank line (track prev_blank)
    - Preserve leading whitespace (indentation)

    **5. strip_scaffolding(content: str) -> str**
    Per D-02 and D-04: Remove lines matching these patterns:
    ```python
    scaffolding_patterns = [
        r'^\\documentclass\b',
        r'^\\input\{preamble',
        r'^\\begin\{document\}',
        r'^\\end\{document\}',
        r'^\\maketitle\s*$',
        r'^\\input\{sections/',
        r'^\\include\{sections/',
        r'^%\s*\\input\{sections/',  # Commented inactive includes
        r'^\\tableofcontents\s*$',
        r'^\\newpage\s*$',
        r'^\\thispagestyle\{[^}]*\}\s*$',
        r'^\\vspace\{[^}]*\}\s*$',
        r'^\\hrule\s*$',
    ]
    ```
    Also skip pure comment lines starting with `%` (except commented includes handled above).

    **6. verify_structure(structure: Structure, base_path: Path) -> tuple[bool, str, dict]**
    Process flow:
    1. Read original file, normalize line endings
    2. Resolve includes in original (some originals have `\input{}` for preamble)
    3. Normalize whitespace
    4. Strip scaffolding
    5. Repeat steps 1-4 for modular file
    6. Generate unified diff with `difflib.unified_diff(original_lines, modular_lines, n=3)`
    7. Return (passed, diff_output, stats) where passed=True if no diff lines

    **7. main() function with argparse**
    - `--structure` / `-s`: Filter by partial name match
    - `--output` / `-o`: Custom output path (default: `verification/content_verification_report.md`)
    - `--verbose` / `-v`: Print progress
    - Default output path: `pinn_instruction/original_latex/verification/content_verification_report.md`

    **8. Report generation (Markdown)**
    Per D-07:
    ```markdown
    # Content Completeness Verification Report

    **Generated:** {date}
    **Structures verified:** {count}

    ## Summary
    | Structure | Status | Original Lines | Modular Lines |
    |-----------|--------|----------------|---------------|
    | {name} | PASS/FAIL | {count} | {count} |

    ## Detailed Results

    ### {structure_name}
    **Inactive sections excluded:** {list if any}
    ```
    {diff or "No differences found."}
    ```
    ```

    Per D-05 and D-08: For each structure with inactive_files, show "**Inactive sections excluded:** ..." before the diff. When no differences, show "No differences found." per D-08.

    **9. Exit code**
    Return 0 if all structures pass, 1 if any fail.

    **Create the verification directory first:**
    ```python
    output_path.parent.mkdir(parents=True, exist_ok=True)
    ```

    Use only Python built-in modules: `re`, `argparse`, `pathlib.Path`, `difflib.unified_diff`, `dataclasses.dataclass`, `typing.Optional`.
  </action>
