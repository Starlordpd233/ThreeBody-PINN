<objective>
Close the central Phase-41 architecture gap (RESEARCH Pattern 4): extend `pinn/training/controllers.py` so the monolithic Phase-40 loop can checkpoint and guard MID-STAGE. Expose the live Adam optimizer and the four-stream RNG state in `RunController.state_dict()`, thread a global cross-stage step counter, add optional per-step checkpoint + guard hooks inside both optimizer phases, wire the `CurriculumController` disposition ledger (`curriculum.jsonl`) + ordered/idempotent promotion, and compose the complete Adam reset across a stage boundary with checkpoint save/restore.

This is the prerequisite that makes CTRL-02 (dual-trigger cadence firing during a stage), CTRL-03 (mid-stage atomic writes), CTRL-06 (Adam reset preserved through save/restore), CTRL-07 (per-step guards), and CTRL-08 (exact next-step RNG draws) testable at all — none of which the Phase-40 `run_stage` could do. Every extension is ADDITIVE (hooks default None, state keys additive) so the Phase-40 suite stays green.

Purpose: the composition seam 41-05's `pinn.train` drives end-to-end.
Output: extended `pinn/training/controllers.py` + `tests/phase41/test_controllers_ext.py`.
</objective>
