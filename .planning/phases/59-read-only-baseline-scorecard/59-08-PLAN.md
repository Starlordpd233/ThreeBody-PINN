<objective>
Score the two no-learning comparison points every later result is read against
(FEAS-07): the two-Kepler formula and the nearest-neighbour copy.

In plain language: a network only "counts" if it beats a formula a first-year physics
student could write, which treats the inner pair and the outer body as two separate
textbook orbits. A second yardstick asks whether simply copying the most similar
training system already predicts a validation system well, which tells the owner how
densely 1,812 systems cover Stage 0. This plan scores both with the same scorer the
networks will face, before any rung runs.

Purpose: D-15, D-16, D-17 (both baselines committed before any rung, because the
counting rule depends on them), D-38, D-40 (validation records are read here only
for the validation panel FEAS-07 scores), and the owner's question whether the
formula already reaches Tier 1 on Stage 0. Each row also carries the FEAS-01(i)
physics-residual context column, so the comparison points report the same columns
the networks will.

Output: two_kepler.py, nn_copy.py, the baselines runner, tests, and the baselines
evidence area.
</objective>

The Kepler f-g propagator (59-RESEARCH Pattern 4, validated against RK4 there): r0 = |s0|; 1/a = 2/r0 - |v0|^2/mu (<= 0 means unbound); n = sqrt(mu/a^3); sigma = (s0 . v0)/sqrt(mu); k1 = 1 - r0/a; k2 = sigma/sqrt(a); Newton on dE from M = n*dt for dE - k1 sin dE + k2 (1 - cos dE) - M = 0 (derivative 1 - k1 cos dE + k2 sin dE > 0); r = a + (r0 - a) cos dE + sigma sqrt(a) sin dE; f = 1 - (a/r0)(1 - cos dE); g = dt - (dE - sin dE)/n; fdot = -(sqrt(mu a)/(r r0)) sin dE; gdot = 1 - (a/r)(1 - cos dE); s = f s0 + g v0; v = fdot s0 + gdot v0. In the pipeline frame (r', u) the same masses work unchanged because mu T^2 / D^3 = mu when D^3 = T^2 and G = 1.

Two-orbit assembly: m_ab = m_a + m_b, M = m_ab + m_c; R_ab = COM - (m_c/M) lambda; r_c = COM + (m_ab/M) lambda; r_a = R_ab - (m_b/m_ab) s; r_b = R_ab + (m_a/m_ab) s; the same combinations for velocities, with the COM moving at the initial centre-of-mass velocity.

Formula accelerations (exact second derivative of the assembly, the COM unaccelerated): s'' = -m_ab s/|s|^3 and lambda'' = -M lambda/|lambda|^3; a_a = -(m_c/M) lambda'' - (m_b/m_ab) s''; a_b = -(m_c/M) lambda'' + (m_a/m_ab) s''; a_c = (m_ab/M) lambda''. Same form in (r', u) because D^3 = T^2 and G = 1.
