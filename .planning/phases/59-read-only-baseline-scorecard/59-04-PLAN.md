<objective>
Build the evidence layer every Phase-59 tool writes through, and the independent
verifier that checks the whole evidence chain, including the SCOPE-42 commit order.

In plain language: every number this phase produces is saved as a file with a
fingerprint. The verifier is a separate checker that confirms, mechanically, that the
scorecard was locked before any result existed, that no saved result has changed since
it was made, that no held-out file was opened, that nothing was trained and nothing
under runs/ changed, and that the final report says what the evidence says.

Purpose: the governance constraints require "a verifier subcommand that checks commit
order" (SCOPE-42) and Phase-57-style evidence integrity (per-file SHA-256 manifests,
--check re-derivation, DIAG-07 results hash-checked rather than re-run).

Output: pinn/verification/evidence_io.py, the verifier script, the evidence README
(the contracts the later plans follow), and their tests. This plan reads no corpus
file.
</objective>
