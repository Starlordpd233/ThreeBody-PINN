<objective>
Build the FEAS-01 scorer and prove it reports exactly what it should with the D-10 known-error tests.

In plain language: this is the instrument that turns a predicted orbit into the
scorecard's numbers. Before it is trusted on anything real, it is run on orbits whose
exact error is known from a formula, and must report that error.

Purpose: Phase 60's harness, Plan 59-08's comparison points and Plan 59-09's JX-4 all
score through this module. It uses the gate's own Hamiltonian and eps_H functions, but
feeds them autograd (network), analytic (formula) or Brutus (copy) velocities, never
finite differences (D-30, GAP-59-02).

Output: pinn/verification/feasibility_scorer.py and its tests and fixtures. Synthetic
data only; no corpus file and no checkpoint is opened.
