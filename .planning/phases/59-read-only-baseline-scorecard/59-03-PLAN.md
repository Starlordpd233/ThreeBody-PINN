<objective>
Build the single doorway through which Phase-59 code reads the dataset, and the
repository scans that keep every other Phase-59 file from going around it.

In plain language: the held-out exam files must never be opened. Instead of trusting
each tool to be careful, every tool reads through one module that knows the list of
allowed files (training and validation only), refuses anything else before it even
works out where the file is, and keeps a log of every file it opened. Automated scans
then check that no other Phase-59 file reads the dataset, trains anything, or imports
the held-out evaluator.

Purpose: D-26, D-35 and D-27. FEAS-02, FEAS-07 and FEAS-08 each require "only
training- and validation-split files are opened, and this is asserted"; DIAG-07
requires "no test split is opened". This plan is where that assertion lives.

Output: split_allowlist.py, production_reference.py, their tests, the static guards
and the one-line extension of the Phase-39 corpus-reader allowlist.
</objective>
