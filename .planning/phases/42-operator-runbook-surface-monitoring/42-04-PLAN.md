## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| training process → `train.log`/`train.log.jsonl` | Handoff artifacts read later by an operator / fresh checkout; must be parseable and identity-clean |
| non-finite step values → JSON | A raw NaN produces invalid JSON that breaks every downstream parser |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-42-01 | Information Disclosure | `train.log`, `train.log.jsonl` | high | mitigate | Record run-directory-relative paths only; no home-directory absolute path / hostname / secret (CTX-79); enforced by the 42-09 redaction grep (must-NOT #2) |
| T-42-09 | Tampering (log integrity) | JSONL serialization under divergence | high | mitigate | Sanitize to `null` + `finite/nonfinite_keys` then `json.dumps(allow_nan=False)` (CTX-67, E1) — a diverged line stays parseable, never a raw `NaN` invalid-JSON line |
| T-42-04 | Denial of Service (self-inflicted) | JSONL/human handler `emit` | medium | mitigate | Append + `flush` per record (no fsync, no atomic path); `handleError` swallows sink exceptions so a logging failure never kills the step loop |
| T-42-SC | Tampering (supply chain) | stdlib json/logging | low | accept | Stdlib only; no install |
</threat_model>
