step-emission point (`RunController._log_step`) with the OPS-03/04b field set,

additive, backward-compatible `return_details=` path.

panel (42-05) all fan out from the same widened `_log_step` `extra=` dict and the
same detached loss details — those consumers cannot be built until this substrate
exists. This is the "spine before sinks" foundation.

Output: a modified `causal_physics_loss` with a detached details path and a
widened, guard-order-corrected `_log_step` emitting from both optimizer phases.
</objective>
