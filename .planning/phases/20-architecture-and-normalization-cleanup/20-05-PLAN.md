**Architecture:** Source-backed documentation-cleanup adjudication (baseline non-EVID-05). Create/fill `evidence/D-02-NORM.md` from `_TEMPLATE.md`, citing `ctl_pinn_resolution.md` and `01-architecture-and-physics-foundations.md` side by side; confirm the sources agree on the raw-vs-bounded distinction; record one enum verdict and a Locked Convention. Then align the `I_norm` surfaces in `ctl_instruction.md` per that verdict, and run positive + negative audits. **This plan runs after 20-03 (I_3) and 20-04 (energy/mass support), both of which edit `ctl_instruction.md`; re-locate every `I_norm` surface by section anchor / `rg`, not by line number.**

**Tech Stack:** Markdown framework spec; shell validation with `rg` and `git`. No Python, no tests, no `pinn/` code.

**Post-review remediation note (2026-06-06):** `GAP-20-01` option (a) authorizes the raw-only framework-spec closure. `I_norm_raw` is the only required live spec surface; `I_norm_in = tanh(I_norm_raw)` remains the D-02-NORM convention for a conditional widened-input ablation, not a required `ctl_instruction.md` input surface. The strengthened audit also covers the Step 4 scope descriptor list and both LaTeX bare-name forms (`I_{\text{norm}}` and `I_{\mathrm{norm}}`).
