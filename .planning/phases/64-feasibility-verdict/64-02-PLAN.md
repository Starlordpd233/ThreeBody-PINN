<objective>
Write the number manifest, `evidence/numbers.json`: every number the verdict and the charter will quote, each with where it comes from and how it was computed. Add the two checks that re-derive it independently: `numbers` (from the committed records) and `derive` (from the committed network weights, on the CPU).

In plain language: before writing the verdict, every number it will contain is computed by a program and saved in one file, and a second, separate program computes each one again and must get the same answer. The new numbers, such as how much the trained network's output moves over time compared with the real orbit, are computed by re-scoring the saved weights on the CPU in a few seconds. Nothing is trained.

Purpose: FEAS-06 (every quoted number re-derived; the time-constant evidence of D-01 committed so the verdict may quote it) and FEAS-10 (the cost and baseline numbers the charter quotes, D-05, D-11). FEAS-06's adjacency and ordering edges are proved here.

Output: `build_phase64_evidence.py`, `numbers.json`, the `numbers` and `derive` modes and their tests.
</objective>
