<objective>
Build the ACC-01 `verify` pre-flight ladder: a single `python -m pinn.verify` command that runs the five verification rungs in order, aggregates a per-rung and overall PASS/FAIL verdict, exits non-zero naming the first failing rung, and writes a verdict marker that plan 43-04's launch gate consumes. Also stand up the `tests/phase43/` package scaffold (shared skip-phrase + re-exported fixtures) that every other Phase 43 plan's tests depend on.

Purpose: This is the milestone-closing verification entry point. It converts four standalone probe CLIs into one gated ladder (CTX-70) and produces the freshness marker the >30-min run gate needs.
Output: `pinn/verify.py`, the `tests/phase43/` scaffold, and the verify-ladder test module.
</objective>
