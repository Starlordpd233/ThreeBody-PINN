<objective>
Execute the ACC-02 ~5-minute smoke test on real admitted Stage-0 data and capture the measured s/step + per-run forecast, pausing for two owner ratifications: the B-5 resume-field list BEFORE run #1, and the D4-a wall-clock ceiling value AFTER the smoke (from the measured s/step, in r1b's 15–30 min range). </objective>
