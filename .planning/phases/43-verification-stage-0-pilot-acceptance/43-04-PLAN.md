<objective>
Add the ACC-01 duration gate to the `pinn.train` launch preflight (CTX-71): a run whose smoke-forecast is strictly > 30 min is refused unless a fresh green `verify` marker exists (matching env, within the freshness window). The gate fails closed BEFORE any expensive run-dir/checkpoint state is created, matching train.py's existing fail-closed-before-construction discipline.

Purpose: This is the second half of ACC-01 — the ladder (plan 43-01) proves the env/checkpoint is healthy and writes a marker; this gate makes that proof a precondition for long runs. The ~5-min smoke is exempt because its forecast is well under 30 min.
Output: the >30-min launch gate in `pinn/train.py` + a launch-path test.
</objective>
