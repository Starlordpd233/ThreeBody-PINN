<objective>
Close the ACC-01 long-run authorization bypasses (CR-03, CR-04). The >30-min
duration gate must fingerprint the runtime training will actually execute, and a
verify marker must be validated against the complete schema before it can
authorize a long run.

Purpose: the smoke calibration + verify marker are the only artifacts that let an
expensive run past the 30-minute safety gate; both authorization identities were
forgeable, so the gate was not actually protecting the operator.
Output: an effective-runtime-keyed duration gate, a schema-validated marker
predicate, and regression tests that flip the two reproduced bypasses to refusal.
</objective>

- `pinn.train._check_duration_gate` and `pinn.train._write_smoke_timing_calibration` rewired to use the effective labels.
- `pinn.verify` marker-schema validation (a `_marker_ladder_is_valid`-style predicate plus schema-version + fingerprint-shape checks) applied inside `marker_is_green_and_fresh`.
- New tests in `tests/phase43/test_verify_gate.py` (strict-CPU effective fingerprint) and `tests/phase43/test_verify_ladder.py` (forged/duplicate/reordered/missing/unknown-rung/stale-schema marker refusal).
