## First-Principles Physics Check

Start from Newton's equation:

```math
\frac{d^2 r_i}{dt^2} = G \sum_{j \ne i} m_j
\frac{r_j-r_i}{||r_j-r_i||^3}.
```

Substitute `r = D*r'` and `t = T*u`. Then
`d^2 r_i / dt^2 = (D/T^2) * d^2 r_i'/du^2`, while the force term becomes

```math
G \sum_{j \ne i} m_j
\frac{D(r_j'-r_i')}{D^3 ||r_j'-r_i'||^3}.
```

After multiplying by `T^2/D`, the dimensionless equation is

```math
\frac{d^2 r_i'}{du^2} =
\frac{G*T^2}{D^3}
\sum_{j \ne i} m_j
\frac{r_j'-r_i'}{||r_j'-r_i'||^3}.
```

The spec's target residual keeps raw masses `m_j` with unit coefficient, so
`G*T^2/D^3 = 1` and therefore `D^3 = G*T^2`. This fixes
`D=(G*T^2)^(1/3) ~= 4.6416` for `G=1`, `T=10`.

The issue doc's `6.694` value corresponds to the mass-fraction alternative
`D = (G*M_tot*T^2)^(1/3)` with the physical total mass `M_tot = 3` used in the
issue-doc example. That convention produces the residual coefficient
`m_j/M_tot`, so it is a different framework convention requiring a framework-wide
rewrite.

## Root-Cause Framework Ambiguity

The ambiguity is a pre-existing convention choice: raw mass versus mass fraction.
Before Phase 19, the framework used `D=(G*T^2)^(1/3)` and raw masses but did not
explicitly lock the convention. Phase 19 locks raw mass as the governing convention.

## Locked Convention

Raw-mass nondimensionalization is locked for PHYS-01. The characteristic length is
`D=(G*T^2)^(1/3) ~= 4.6416`. The mass-fraction alternative
`D=(G*M_tot*T^2)^(1/3)` would require touching every residual, Hamiltonian,
angular-momentum, COM, and invariant formula and is documented as a future rewrite
only.
