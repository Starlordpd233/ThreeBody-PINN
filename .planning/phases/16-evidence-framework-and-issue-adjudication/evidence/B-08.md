Summary: the current pseudo-ALM formulation
`+λ_p L_phys + (μ_p/2) L_phys²` is rejected because squaring a nonnegative MSE
produces a quartic residual. The default loss removes ALM entirely. Optional ALM
is P2 only, scalar conservation constraints only, never on dense ODE residual,
and never during L-BFGS.

The sources agree after the ALM scope restriction is applied: resolution doc
§8.8 gives the rejection and optional-ablation scope, Phase 19 D-05 locks that
verdict, and the Phase 16 ledger records B-08 as not contested.
