## First-Principles Physics Check

<!-- REQUIRED for EVID-05 -->

The relevant source object (spec + resolution doc) is the ratio form, so the 20-RESEARCH ARCH-03 Conditional Lemma (`.planning/phases/20-architecture-and-normalization-cleanup/20-RESEARCH.md:154-186`) applies. The derivation is reproduced and independently verified here so the verdict can be reviewed without trusting either primary source.

Let the sorted side lengths be $a \le b \le c$ with $I_3 = (a+b-c)/(a+b+c)$.

- **Lower bound.** The triangle inequality gives $c \le a+b$, so the numerator $N = a+b-c \ge 0$; the denominator $P = a+b+c > 0$. Hence $I_3 \ge 0$, with equality iff $c = a+b$ (the degenerate / collinear configuration).
- **Upper bound.** For fixed $S = a+b$, $I_3 = (S-c)/(S+c)$ is strictly decreasing in $c$, so $I_3$ is maximized at the smallest admissible $c$. Since $c \ge b \ge S/2$, set $c = b$: then $I_3 = a/(a+2b)$, which is increasing in $a$ with $a \le b$, so the maximum is at $a=b$, giving $a/(3a) = 1/3$. This is the equilateral configuration ($a=b=c$).

Therefore $I_3 \in [0, 1/3]$ (0 = collinear/degenerate, $1/3$ = equilateral). The linear map $I_3^{in} = 6I_3 - 1$ sends $0 \mapsto -1$ and $1/3 \mapsto 1$, a bijection onto $[-1,1]$.

This **confirms the resolution doc** ($[0,1/3]$, $6I_3-1$), **contradicts the current spec's raw annotation** ($[-1,1]$ is the mapped range, not the raw range), and shows the issue doc's "$[0,1]$ / $2I_3-1$" is correct only for its own sorted-distance object, not for the ratio-form quantity. Consistency cross-checks: `REQUIREMENTS.md:49` (map the documented triangle-shape range to $[-1,1]$ — satisfied by $6I_3-1$) and resolved `GAP-17-05` (I_3 is staging metadata, not a network IC slot — preserved, spec `:672-673`).

## Root-Cause Framework Ambiguity

<!-- REQUIRED for EVID-05 -->

Two compounding gaps allowed the sources to disagree:

1. **Missing raw-vs-mapped distinction.** The spec's §3.4 annotated the *raw* ratio-form `I_3` with its *mapped* range `[-1,1]`, providing no explicit raw range and no staging map. This conflation is the literal defect.

With no single locked `I_3` definition recorded earlier, the M5 finding's recommendation ($[0,1]$, `2*I3-1`) was derived against a different object than the one the spec encodes.
