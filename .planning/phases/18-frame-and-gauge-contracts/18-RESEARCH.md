The `ctl_instruction.md` edit should replace current Step 2 and Step 2.5 with one "Step 2: Unified Preprocessing Pipeline" in this order:

1. parser contract and mass-invariance check;
2. COM recenter and zero-momentum boost;
3. canonical ordering;
4. canonical rotation gauge;
5. global scaling;
6. COM/momentum assertions and stored per-trajectory metadata.

Do not leave the old Step 2.5 author note as normative text.

### Sampling Code Is Authoritative For FRAME-03

Before touching `sampling_method.md`, read:

- `simulation_data/Scripts/ic_generation/generate_ics.py`
- `simulation_data/Scripts/ic_generation/ic_generation_utils.py`
- `simulation_data/Documentation/README.md`

The key facts to preserve are:

- hierarchical generation enforces COM/P, then applies Gaussian perturbation with sigma `0.01` to all position and velocity vectors;
- standard quasi-random positions use `p3 = -(p1 + p2)` for equal-mass COM;
- standard quasi-random velocities use `v1 = -v2/2` and `v3 = -v2/2`, so total momentum is zero for equal masses;
- `scale_range=(0.8, 1.2)` is enabled in the generation entrypoint for standard quasi-random data, but Phase 18 must not rewrite the Phase 20.5 Sobol coordinate-allocation target.
