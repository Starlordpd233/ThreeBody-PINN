<objective>
Build the committed render detector that is the source of truth for "what is broken" across all of Phase 22. This is Wave 0 — every WS-A repair plan and the final validation depend on it. The detector mirrors the Cursor/VS Code KaTeX engine (`markdown-it` + `@vscode/markdown-it-katex` + `katex`), runs the 6-layer scan (D1–D6) plus a plugin double-wrap sanity gate, enumerates author-flagged comments in any form/format (census mode), and reproduces the live author-flag regression set while keeping both negative controls clean (G1). It also runs the Stage-0 footnote probe so the 37 `[^n]` refs / 17 defs in `pinn_architecture.md` can be correctly classified as survivors-or-not before any repair.

Purpose: Without the detector and the footnote probe, no repair task can be verified or correctly scoped. This plan establishes the automated oracle (G1/G2), the census mechanism (D-06 input), and resolves the one assumption (A2 footnote rendering) that materially changes the defect count.

Output: `tools/spec-render-check/` (detector + pinned package.json + committed lockfile + README + regression fixtures) and `22-STAGE0-FOOTNOTE-PROBE.md`.
</objective>
