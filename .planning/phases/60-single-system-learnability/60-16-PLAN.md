<objective>
If the sweep found a setting that reaches Tier 1, run the single pre-registered confirmation
on the second failing system and record whether it is a rescue.

In plain language: one setting looked like it fixed the first failing orbit. This checks it
once on another failing orbit. If it holds, the owner is asked whether to continue the ladder
at a non-locked setting; if it does not, the owner decides what that means.

Purpose: FEAS-03's confirmation (SPEC Requirement 6) and GAP-60-09's procedure.

Output: one confirmation record with its weights and `evidence/g2/rescue.json`, or a
"branch not taken" SUMMARY.
</objective>
