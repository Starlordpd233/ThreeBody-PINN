<objective>
Give the harness its physics terms by composing the trainer's own functions, and prove the
composition is the trainer's: one harness step must produce the same losses and gradients as
the production trainer's memory-bounded step, and patching any trainer function must move the
harness output.

In plain language: Rung 2 asks whether the network learns from the equations of motion. That
answer only counts if the harness uses exactly the trainer's equations, so this plan builds
the physics step from the trainer's functions and tests it against the trainer itself.

Purpose: INST-05(a) (mutation in the manner of INST-04 SC3), FEAS-04 arms (a) and (b)
composition, D-06 (log the frozen monitor at readings; never halt), the chunked memory rule,
GAP-60-05's physics freeze. Wiring into the runner (schedule, warmup, readings, R_ref in
force, S_H) is Plan 60-11.

Output: the physics half of `learnability_losses.py` and `tests/phase60/test_losses_trainer_functions.py`.
</objective>
