<objective>
Make a real arm survivable and accountable as a process: it starts only through admission
under a single lock, records its own PID, stops cleanly on a hangup, interrupt or terminate
signal at a safe point, and resumes exactly where it stopped, including inside the L-BFGS
polish; anything else is refused and goes to the owner.

In plain language: a three-to-seven-hour experiment must survive the owner needing the
machine or a closed laptop lid. This plan lets the experiment pause on request and pick up
exactly where it left off, with the same numbers, while refusing to restart anything that
ended badly.

Purpose: SPEC Requirement 8 (resume including the polish; summed Adam time; budget not
re-timed; an arm that cannot resume goes to the owner), SCOPE-44 (one at a time), CONTEXT
discretion (a handler saves a checkpoint when the run is terminated or its terminal closes;
resume refuses missing L-BFGS segment state).

Output: the command line and lifecycle in `learnability_run.py`, `tests/phase60/test_resume.py`,
`tests/phase60/test_cli.py`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operating system signals -> a running arm | a hangup, interrupt or terminate must become a checkpointed, resumable stop |
| resume checkpoint on disk -> a resumed arm | a pickle-free payload restored only under the same protocol and code |
| two shells -> the machine | two arms must never run at once |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-60-02 | Tampering / Elevation | resume.pt loads | high | mitigate | torch.load with the literal weights_only=True; payload of tensors and plain containers; static guard |
| T-60-07 | Repudiation / Tampering | silent restart or replacement | medium | mitigate | claim and record exclusivity, stop markers per stop, refusal on drift or missing segment state; ResumeRefusalTests and SignalSubprocessTests |
| T-60-09 | Denial of service | concurrent arms | medium | mitigate | begin_long_step one-launch lock under the Phase 60 evidence root; LifecycleTests |
| T-60-11 | Elevation of privilege | owner-routed exits | high | mitigate | single top-level mapping to exit 3 with no retry; ExitMappingTests |
| T-60-12 | Tampering | code drift between segments | high | mitigate | resume refuses any change of protocol SHA-256 or pinned module digest |
| T-60-SC | Tampering | package installs | low | accept | none |
</threat_model>
