<objective>
Fix the shared scorer so it can score a network that lives on Apple's MPS device, record
the scorer's new fingerprint as the single permitted successor, and prove that the frozen
L-BFGS polish runs on MPS at all before any real arm depends on it.

In plain language: the scoring code crashed when the network sat on the Mac's GPU, because
the GPU cannot hold 64-bit numbers. The fix moves numbers to the CPU first and only then
widens them. The plan also checks, with a small test, that the second optimizer the
experiments use works on the Mac's GPU.

Purpose: SPEC Requirement 3, D-09 (part 1: the committed successor record), and the
orchestrator's MPS L-BFGS smoke (60-RESEARCH Assumption A1). Plan 60-04 teaches the Phase 59
verifier to accept the successor. This plan runs after Plan 60-01 (declared in depends_on):
60-01 creates the tests/phase60 package these tests live in, and its fixture tests call the
scorer this plan edits, so the two never run at the same time in the shared tree.

Output: the edited scorer, `evidence/scorer-successor.json`, two test modules.
</objective>
