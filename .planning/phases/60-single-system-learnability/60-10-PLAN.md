<objective>
Build the pre-registration machinery: a run protocol that pins every rule and every line of
code a real arm will use, a preflight record of every assigned data file, and an admission
check that lets an arm start only when the protocol, the data, the amendment and the ladder's
recorded branch all allow it.

In plain language: before the first real experiment, the project writes down exactly how
every experiment will run and fingerprints the code that will run it. Each experiment then
refuses to start if anything changed, if its data file is missing, or if the earlier results
say it should not run.

Purpose: SPEC Requirements 4 and 8 (protocol before the first rung; every assigned record
checked before the first arm), the orchestrator's pre-registration list (constraint 8), D-08,
D-11, GAP-60-03..13 as protocol fields. Plan 60-13 writes and commits the real protocol and
preflight; Plan 60-12 wires admission into the runner's command line.

Output: `learnability_protocol.py`, `tests/phase60/test_protocol.py`, `tests/phase60/test_admission.py`.
</objective>
