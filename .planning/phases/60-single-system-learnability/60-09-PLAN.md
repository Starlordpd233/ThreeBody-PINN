<objective>
Prepare the step the owner's "continue" requires before any physics arm: re-measure the
reference residual scale and re-run the train-free gate at the approved `first_omega_0`,
without touching the governed Stage-0 reference.

In plain language: if the owner approves a different first-layer frequency, the physics
term's reference scale has to be measured again at that setting, and the network's
starting-point check has to pass again, before any physics experiment. This plan builds that
measurement so it writes only Phase 60 files and cannot overwrite the reference everything
else uses.

Purpose: D-07, GAP-60-10 (the reference in force after a continue is the re-measured one),
GAP-60-11, Pitfalls 1, 5 and 9 of 60-RESEARCH. The real re-measure runs only on the continue
path (Plan 60-19).

Output: the seam in `gate04_train_free.py`, `gate04_omega_remeasure.py`, and its tests.
</objective>
