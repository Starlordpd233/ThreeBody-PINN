<objective>
Turn the measurement core into re-runnable, self-documenting tooling: a CLI whose
zero-argument invocation reproduces the six audited rows, a config surface that
drives an arbitrary case list, and an evidence writer that records the run
re-derivably.

Purpose: SC2 requires the reproduction be "recorded re-derivably (command, tree
state, full output) per the GAP-44-02 discipline"; D-02 requires genuine
configurability so Phase 56 can invoke the same tool under a new recipe without
new code. This plan also lands the one required modification to an existing
Phase-38 test file that PATTERNS.md identified as a verified mechanical
collision.

Output: `main(argv)`, `load_cases_config`, the evidence writer and provenance
capture in the probe module; the CLI/config/evidence test suite; and the
`_EXCLUDE_SUFFIXES` entry in `tests/phase38/test_prohibitions.py`.

Decisions implemented by this plan:
- D-02: the CLI and config half of the general config-driven sweep — an
  `argparse` `main(argv)` matching the established `pinn/verification/*_probe.py`
  convention, whose `--precision` and `--device` flags are defaulted rather than
  required so a zero-argument invocation reproduces exactly the six audited rows,
  and whose `--cases-config` JSON surface drives an arbitrary case list. The
  Python API half landed in plan 55-01. This is also the change that forces the
  documented Phase-38 prohibition exclusion in Task 2.
</objective>
