<objective>
Build the mechanical capability for the ratified 4096-total / 256-per-bin /
16-bin collocation structure, unit-test it directly against synthetic residual
arrays, and prove by construction that nothing in this phase's default
measurement path can reach it.

Purpose: CONTEXT.md D-03 splits this cleanly — Phase 55 owns building the
capability so Phase 56 can invoke the same tool under the new recipe without new
code, and Phase 56 owns actually running it, computing the ratified reference
scale, and persisting it with full provenance. This plan lands the first half and
mechanically enforces the boundary between them.

Output: `stratified_collocation_times` and `bin_mean_residuals` plus their
ratified structural constants in the probe module; synthetic-input correctness
tests; and two containment tests that fail if the helpers ever become reachable
from the default sweep.

Decisions implemented by this plan:
- D-03: build the new-structure capability, do not exercise it as a milestone
  artifact. The tool becomes mechanically capable of the ratified
  4096-stratified / 256-per-bin / 16-bin structure and the binning and bin-mean
  logic is unit-tested directly against synthetic residual arrays, while the real
  six-case sweep is never run under that configuration and no reference-scale
  number is produced, printed or persisted anywhere in Phase 55. D-03 records its
  own reversibility as one-way if violated, which is why a `checkpoint:decision`
  precedes the implementing task.
- D-02: the same general sweep surface is what lets Phase 56 invoke this tool
  under the new structure without new code; nothing here narrows it.
</objective>

    - `stratified_collocation_times(n_bins=16, per_bin=256, rng=numpy.random.default_rng(0))` returns a 4096-element ascending time array and a 4096-element integer bin-index array.
    - Exactly 256 entries carry each bin index 0..15.
