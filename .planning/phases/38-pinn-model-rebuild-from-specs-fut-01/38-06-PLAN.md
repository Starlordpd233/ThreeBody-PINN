<planner_assumptions>
## Fixed rung-4 parameters + edge R5 (planner build-engineering values, recorded with rationale)

- **PASS gate:** data-loss reduction ratio `L0 / Lf >= 1e3` (SPEC AC — the falsifiable operationalization of "near-zero"; the exact floor Lf is recorded evidence, not an invented ratified constant).
- **Bounded optimization:** Adam on the DATA term only (overfit one trajectory), bounded by a documented `--max-steps` default (e.g. 3000). Rationale: overfitting one trajectory's data term is a small, fast smoke of the model+AD+loss wiring; a fixed cap makes non-convergence a bounded FAIL, never a hang.
- **Edge R5 (non-convergence/divergence must FAIL loudly, not hang) — planner assumption:** a NaN/Inf loss at any step triggers an immediate typed FAIL with the step recorded; reaching `--max-steps` without the >=1e3x reduction exits FAIL; there is no unbounded loop and no silent "close enough." Per 38-SPEC Edge Coverage this is a surfaced planner assumption, not a held-out test obligation.
- **In-worktree run:** because no Brutus payload exists in this worktree, the automated test overfits a tiny synthetic in-format tmp trajectory (the model overfits whatever single trajectory it is given, so the >=1e3x reduction is demonstrable in-worktree); the operator runs the probe against the real recommended-default trajectory (38-03 `<default_trajectory>`) at execution for the recorded evidence.
</planner_assumptions>
