## Fixed rung tolerances + edge handling (planner build-engineering values, recorded with rationale)

- **Rung 2 gradcheck tolerances:** `torch.autograd.gradcheck` under fp64-CPU with `eps=1e-6, atol=1e-5, rtol=1e-3` (the standard double-precision gradcheck values; the fp64-CPU arm is the reference where finite-difference gradcheck is meaningful, per the R-6 dual-arm framing). The probe prints these and the pass/fail.
- **Rung 3 — dual PASS gate (finding codex/claude-max HIGH #3, teeth on ground truth):** rung 3 PASSes only if BOTH gates hold.
  - **Gate A (always-on) — force-energy self-consistency (cycle-2 HIGH #3, tautology fix — autograd path MANDATED):** obtain the potential-gradient force via AUTOGRAD, never a hand-coded closed form. Build the scalar matched-Plummer potential `V_eps = -sum_{i<j} m_i m_j / r_safe` on position leaves with `requires_grad=True`, then take `grad_i = torch.autograd.grad(V_eps, positions)` — this is the ONLY sanctioned mechanism; a hand-coded `-dV_eps/dr'_i` would reproduce `softened_acceleration`'s exact closed form and reduce Gate A to a self-comparison with no verification value (and the mutated-force falsifiability test would still pass, so nothing would force the independent path). The autograd force is `F_i = -grad_i = m_i * a_i`; compare the implied acceleration `a_i^V = -grad_i / m_i` (divide out the per-body mass, since `F = m a = -grad V` — short first-principles) against the direct `softened_acceleration_i` to `relative_error < 1e-5` (`pinn_architecture.md` §10.4, `--residual-threshold` override). This is a genuine autograd-through-the-potential vs closed-form-force consistency check, computable on any geometry (including a synthetic fixture), but it is BLIND to shared errors in `D` / mass convention / `eps_soft` because both sides use the same constants — which is why Gate B is required.
  - **Gate B (ground-truth teeth) — Newtonian-residual band:** on the supplied dense trajectory, compute the Newtonian residual `||f_i|| = ||a'_fd - sum_{j!=i} F_ij||` and its per-snapshot relative magnitude `||f_i|| / ||a'_fd||`; PASS if the MEDIAN relative residual (over qualifying snapshots) is below `--newtonian-residual-threshold` (default 1e-1). Because `a'_fd` is finite-differenced from the ACTUAL trajectory (independent of `D`/mass/`eps_soft`) while `sum F_ij` uses those constants, a systematic mis-scaling makes the two disagree at O(1) → FAIL. This is the gate the self-consistency identity cannot provide. The default 1e-1 band is coarse (a correct wiring sits at the ~1e-3 finite-difference truncation floor); the operator records the measured floor on the first real run and MAY tighten via the override.
  - **Finite-difference scheme (finding deepseek M1 / kimi H3 reproducibility; cycle-2 HIGH #1 dimensional fix):** difference the physics-layer velocity `v'` with respect to the dimensionless leaf `u = t/T`, NOT raw Brutus time. Convert first: `u(n) = t(n) / T`, `r'(n) = r(n) / D`, and the physics-layer velocity `v'(n) = dr'/du = v_raw(n) * (T / D)` (raw Brutus velocity times `T/D` — NOT `v_raw/D`). Then `a'_fd(n) = (v'(n+1) - v'(n-1)) / (u(n+1) - u(n-1))` — second-order CENTRAL difference with denominator `Delta u = Delta t / T`, one-sided (forward at the first snapshot, backward at the last) at the endpoints. Use `T = T_CHARACTERISTIC_TIME` (= 10.0) and `D = D_CHARACTERISTIC_LENGTH` from `pinn.constants`. Dimensional grounding (pinn_architecture.md:980 `T = t_max`, `D = cbrt(G T^2)`; :892/:897 the `(u, r', v')` physics layer with `v' = dr'/du`; ctl PIPE-09 `D^3 = G T^2`): because `D^3 = G T^2`, the softened force `sum F_ij` in `r'` units already equals `d^2 r'/du^2` (i.e. `a'` on the u leaf), so the finite difference MUST be taken on the u leaf. The earlier raw-t / `v_raw/D` form gave `a'_fd = a_raw/D` versus `sum F_ij = (T^2/D) a_raw` — off by `T^2 = 100`, making Gate B FAIL a correct implementation (agy HIGH). After the fix a correct trajectory lands at the ~1e-3 truncation floor; a wrong `D` (e.g. the rejected 6.694) lands at O(1) because `a'_fd` scales as `T^2/D` while `sum F_ij` scales as `D^2` and only `D^3 = T^2` reconciles them.
- **Edge R3 (softening-active points) — planner assumption:** the residual rung excludes snapshots whose minimum pairwise separation is below `--min-separation-guard` (default 1e-3 in r' units, ~100x `eps_soft`; at that separation the softening's relative force contribution `(eps_soft/sep)^2 ~ 1e-4` is negligible, so only genuine near-collisions are dropped) and records the excluded count in evidence; the gradcheck rung keeps its synthetic inputs above the softening floor so the fp64 finite-difference check is well-conditioned. Per 38-SPEC Edge Coverage, this is a surfaced planner assumption, not a held-out test obligation.
- **COM-offset recording (finding cycle-2 #9 / claude-max LOW) — planner assumption:** the residual probe computes and RECORDS the ground-truth mass-weighted COM offset `|sum_i m_i r'_i|` in evidence. Gate A (per-body force identity) and Gate B (relative-acceleration band) both compare translation-invariant accelerations, so a nonzero COM offset does NOT bias either gate — the offset is recorded for operator awareness and to parallel the overfit probe's COM guard (38-06), not to gate PASS. The recommended default trajectory (`standard_quasi_random_gold_standard`) is exactly COM = 0 by construction.
