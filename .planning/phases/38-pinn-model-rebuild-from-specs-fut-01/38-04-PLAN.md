<planner_assumptions>
## Fixed rung tolerances + edge handling (planner build-engineering values, recorded with rationale)

- **Rung 2 gradcheck tolerances:** `torch.autograd.gradcheck` under fp64-CPU with `eps=1e-6, atol=1e-5, rtol=1e-3` (the standard double-precision gradcheck values; the fp64-CPU arm is the reference where finite-difference gradcheck is meaningful, per the R-6 dual-arm framing). The probe prints these and the pass/fail.
- **Rung 3 threshold:** the PASS gate is force-energy self-consistency — the analytic gradient `-d V_eps / d r'_i` of the matched-Plummer Hamiltonian equals the residual's force term `sum_{j!=i} F_ij` per body to `relative_error < 1e-5` (grounded in `pinn_architecture.md` §10.4 Force-Energy Consistency, which uses `relative_error < 1e-5`). This gate is a math identity of the implementation, computable on any geometry, so it runs even on the in-worktree synthetic fixture. The probe ALSO reports, as a recorded diagnostic (not the gate), the Newtonian residual `||f_i||` magnitude against finite-difference acceleration on the real dense trajectory — meaningful only on a real ground-truth run. Default threshold overridable via `--residual-threshold`.
- **Edge R3 (softening-active points) — planner assumption:** the residual rung excludes snapshots whose minimum pairwise separation is below a documented guard (near-collision, where r_safe -> eps_soft) and records the excluded count in evidence; the gradcheck rung keeps its synthetic inputs above the softening floor so the fp64 finite-difference check is well-conditioned. Per 38-SPEC Edge Coverage, this is a surfaced planner assumption, not a held-out test obligation.
</planner_assumptions>
