**2. [Rule 3 - Blocking] Em-dash sed pattern needed broader charset**
- **Found during:** Task 9 (em-dash replacement)
- **Issue:** Initial sed pattern `[[:alnum:])]` did not match `---` bounded by `$` (LaTeX math delimiter), leaving 3 prose em-dashes unfixed in review_of_framework.md and sampling_method.md
- **Fix:** Extended pattern to `[^- |]` (negative charset excluding hyphen, space, pipe) which correctly handles `$---word` and `word---$` boundaries while still protecting table separator rows
- **Files modified:** review_of_framework.md, sampling_method.md
- **Verification:** 0 prose `---` remaining in both files, table separators intact
- **Committed in:** `431567c` (Task 9 commit)
