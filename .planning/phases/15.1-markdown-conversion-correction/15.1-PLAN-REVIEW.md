grep -c '^{#item:\|^{#item' pinn_instruction/markdown_conversion/ctl_instruction.md

**C-C3 — Task 9: Sed regex will corrupt table separator on line 96 of `data_quality_assessment.md` (plan lines 349-389)**

The file contains a 22-hyphen table separator:
```
|----------------------|----------------------------------|--------------------------|-------------------------------|
```

The sed pattern `s/\([^ |]\)---\([^ ]\)/\1—\2/g` matches hyphen characters (which are neither space nor pipe), injecting em-dashes into the separator row and breaking table rendering.

**Fix:** Either manually handle line 96 before running sed, or narrow the regex to require word characters:
```bash
sed -i '' 's/\([[:alpha:])]\)---\([[:alpha:](]\)/\1—\2/g' file
```

**C-I2 — Task 13: Verification regex won't catch pre-fix condition (plan line 508)**
