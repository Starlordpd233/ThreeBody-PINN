invariant B record-only, reported `INV-B-N-UNSET open=False`, and still emitted
`eval01_precondition_i=True`. That is a defect against locked decision **D-20**, which states that

structurally ineligible. The implementation stored that divergence GLOBALLY in
`divergence_register.json` — where the owner's 2026-08-05 ruling (the **D-19** evidence packet,
`N = 500`) correctly closed it — while enforcement is configured PER RUN. Closing the global entry
silently re-opened the hole for every N-unset run. The same root cause produces the verifier's
anti-pattern finding: `_consistency_finding` reads the wrong config path, so even the shipped
N = 500 config reports `config_value: None`. Run-local `N` is never actually read or bound.

**GAP B (truth 6).** A schema-valid, `passed`, `stage_boundary`-only artifact with `census=null`
loaded successfully and `_eval01_precondition_i` returned `True`. The predicate trusts the SHAPE of
the assertion list without proving it contains the mandatory run-start table assertion and census
event. Both gaps are the same class: **the predicate does not require the evidence it claims to
summarize.**

Purpose: make an N-unset or evidence-hollow run structurally unable to spend the single evaluation
look, while a genuinely conformant run stays eligible. Passing subsystem and happy-path end-to-end
tests do not falsify either negative case, so both are closed by DISCONFIRMATION tests promoted from
the verifier's own heredoc probes into named, permanent pytest cases (**D-16**: every refusal branch
must have a test that drives it to actually trip).

eligibility predicate living behind the `pinn/conformance/` module boundary (**D-32**), and new

resume history), **D-21** (no proxy for N), **D-23**/**D-26** (register semantics), **D-28** (no

## Reconciliation the executor must hold (read before Task 1)

The committed register entry `INV-B-N-UNSET` is **closed**, with `authority` recording the owner's
2026-08-05 ruling. D-20 says preflight records that divergence as open when `N` is absent. These are
not in conflict once the two scopes are separated:

- The **global register status** records the standing owner decision: `N` was ratified, and
  `configs/stage0-example.yaml` carries it. It stays `closed`. Reopening it would strand the
  conformant N = 500 run.
- **Conformance is per run.** A run whose own config omits the window has not inherited the owner's
  ruling; that run carries the divergence. The run-local record in `assertions[].open_divergences`
  is where D-20's "the run record reports at least one unwaived open divergence" lives.

`49-VERIFICATION.md` endorses exactly this reading ("preserve an open run-local `INV-B-N-UNSET`
divergence whenever N is absent"). Nothing here selects, defaults, or adjusts `N`.
