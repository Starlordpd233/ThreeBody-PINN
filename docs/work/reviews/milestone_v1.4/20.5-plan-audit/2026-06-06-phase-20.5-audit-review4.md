  numpy 2.2.0, scipy 1.17.1) is never mentioned. The dependency preflight (python -c "import numpy, scipy") will fail and suggest pip install numpy scipy —
  potentially polluting system Python instead of using the venv where the probe already passes all assertions.

  Fix: Add to Task 0 a Step 7 that discovers the venv:
  potentially polluting system Python instead of using the venv where the probe already passes all assertions.

  Fix: Add to Task 0 a Step 7 that discovers the venv:

  H2. Task 5 rollback rule references "captured hunk" — nothing is ever captured

  Dimension: Operational Resilience / Partial Failure Recovery
