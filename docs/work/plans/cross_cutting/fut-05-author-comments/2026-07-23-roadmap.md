# FUT-05 Author-Comment Adjudication — Lightweight Roadmap

## Intent

Adjudicate the author comments preserved by v1.4 Phase 22 and handed off in
`.planning/milestones/v1.4-phases/22-framework-spec-cleanup/22-COMMENT-HANDOFF.md`.

This is **not** a full GSD milestone. Phase 22 already did the hard machinery
(census, detector, preservation proof). FUT-05 is a bounded, human-gated
disposition pass under the WS-B engine in the Phase 22 design doc §6.

## Why not GSD here

| Full GSD milestone | Lightweight track (this) |
|--------------------|--------------------------|
| SPEC → discuss → multi-plan execute | One roadmap + living disposition matrix |
| Phase machinery, gap registers, ROADMAP wiring | STOP protocol still applies for semantic gaps |
| Useful when scope is large / multi-agent | Scope is ~25 comments with a known engine |

Promote to a GSD phase only if Wave C (semantic/open questions) balloons into
spec revisions that need multi-phase tracking.

## Grounding sources

1. `22-COMMENT-HANDOFF.md` — inventory only (no prior dispositions)
2. Design §6 WS-B disposition engine — intent class → basis → disposition
3. Live census + detector at adjudication time (re-derive; do not trust line numbers)
4. Prior phase contracts that already touched referents (Phase 22 render cleanup,
   Phase 33 stage-transition, Phase 34 SI-PINN-003, Integrity-R2 clearance, etc.)
5. User adjudication for every non-mechanical disposition

**Live `pinn/` code is not a grounding source** for semantic edits (standing rule).

## Success criteria

1. Every Phase 22 handoff row (H1–H26) has a recorded disposition: REMOVE / KEEP /
   REVISE / RESURFACE / ALREADY-GONE / FALSE-POSITIVE, with basis and evidence.
2. Live census after work is reconciled (no silent losses; meta-doc co-updated).
3. No semantic delete or content rewrite without user confirmation.
4. Residual **DEFINITE** detector findings near syntax-flag comments are either
   fixed under the same track or explicitly deferred with a reason.
5. `sampling_method.md` remains the 0-comment negative control.

## Governance rules (non-negotiable)

- **Default SURFACE.** Misclassification fails safe to human review.
- Deletions on a "no longer reasonable" basis are **never autonomous**.
- Semantic or content-staleness comments that flag *content* (not just a stale
  comment) → surface; do not silently rewrite the content in this track.
- STOP protocol if a disposition requires a physics/spec call with no grounding.
- Atomic commits; explicit owned paths; `scripts/agent-commit` only.
